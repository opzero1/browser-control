Browser Control

Browser Control lets an AI agent that you run on your own computer work in your browser tabs. It is an extension for Google Chrome™ plus a small helper program, called a native messaging host, that you install on the same computer.

The extension does nothing on its own. Until you install the local native messaging host, it stays idle and its toolbar popup shows Disconnected. The extension has no server and makes no network requests of its own.

Who it is for

Browser Control is for developers and other people who use an AI coding agent, or their own scripts, and want that software to use a real browser window that they can watch. You choose the agent. Browser Control only gives it a local way to reach your tabs.

What your agent can do

When your local agent asks, the extension can:

  • List your open tabs, claim one, or open new tabs in the background.
  • Keep the agent’s tabs in a labeled tab group, apart from your own tabs.
  • Read the visible text of a page and the buttons, links and form fields on it.
  • Click controls, type into form fields, and attach a local PDF file to an upload field.
  • Take screenshots and short recordings of the agent’s tabs.
  • Send Chrome DevTools Protocol commands to the agent’s own tabs for advanced automation.

How it works

Install

  1. Install Browser Control from the Chrome Web Store.
  2. Install the local native messaging host and the agent tooling. Both come in chrome-control-skill.zip, which this website hosts and which is built from the source at github.com/opzero1/browser-control. The host needs Node.js 18 or later, and its default setup is for macOS and Linux. For example: 
    curl -fsSL -o chrome-control-skill.zip https://browser-control.pages.dev/download/chrome-control-skill.zip
unzip chrome-control-skill.zip -d browser-control-helper
cd browser-control-helper
node scripts/install-native-host.js --extension-id dcnjjnecbhipdbngkhjppkckpkellmld

    Keep the unpacked folder. Chrome starts the host from it.

  3. Open the Browser Control popup from the toolbar and click Reload host. The popup shows Connected when the extension and the host can talk.
  4. Set up your agent to use the same folder. It contains a SKILL.md file for agent tools and a client that talks to the host. The repository README describes the agent setup.

You stay in control

  • The agent works only in tabs it opened or claimed. Browser Control puts those tabs in a tab group so you can see them.
  • While the extension uses the debugger in a tab, Google Chrome™ shows a notice that the extension is debugging the browser.
  • Click Pause host in the popup at any time. Pausing disconnects the host, stops every agent session, and stays in effect until you click Resume host.
  • When the agent finishes and cleans up, the extension closes only the tabs the agent opened and releases the tabs it claimed.

Privacy

Browser Control has no servers, no analytics, no ads and no remote code. Data stays on your computer unless the local agent you connect sends it somewhere. Read the privacy policy for details.
